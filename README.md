# wikipedia-interest-research

Навичка ([Agent Skills](https://agentskills.io/specification)) для AI-агента: аналізує перегляди Wikipedia різними мовами, оцінює, наскільки можна довіряти тренду, і готує звіт на одну сторінку (PDF) для рішень B2C-продуктів — яку тему розвивати та якою мовою запускатися.

> 🚧 У розробці. Повний README з'явиться на кроці 10.

## Швидкий старт

```bash
brew install uv          # або: curl -LsSf https://astral.sh/uv/install.sh | sh
uv sync                  # відтворюване середовище з uv.lock
scripts/wir --help
uv run pytest
```
