## Процес

Роботу розбито на 12 кроків за затвердженим планом. **Після кожного кроку робота зупинялася:** я показував результат і чекав рев'ю автора. Лише після цього йшов коміт і наступний крок. Автор кілька разів змінював напрям:
- формат звіту;
- повний редизайн PDF за референсами;
- українська термінологія замість кодів мов;
- мінімум коментарів у коді;
- без особливих випадків для окремих мов.

## Як перевірявся результат AI

Головне правило: **нічого не приймалося на віру, включно з власними тестами.** Кожен вид результату мав незалежну перевірку.

| Що перевіряли | Як | Що знайшли |
|---|---|---|
| **Числа переглядів** | Сума денних даних проти monthly-ендпоінта Wikimedia (live-тест); **автор вручну звірив** число з офіційним Pageviews Analysis | Збіг 32/32 місяців; ручна звірка збіглася |
| **Статистичний код** (написаний AI) | Порівняння зі SciPy на 500 випадкових рядах (`dev/verify_stats.py`) | **Помилка** в довірчому інтервалі Theil–Sen (розбіжність до 5 одиниць). Виправлено до повного збігу |
| **Методологія довіри** | Синтетичні ряди з відомою відповіддю + 11 реальних статей | **3 методологічні хиби:** новина визнана «сезонністю»; багатотижнева подія не виявлялася; «неоднозначно» мало високу довіру |
| **Власні припущення AI** | Перевірка на реальних даних перед використанням | Сценарій «мало переглядів» для піклболу в uk хибний (533 на місяць), його замінено. **Польської статті про інтервальне голодування немає**, це пастка першого прикладу |
| **Fact-check** | Навмисні підміни чисел у тексті | **Перша версія не ловила жодної.** Звіряла з усіма службовими числами. Виправлено й покрито тестами |
| **Звіт PDF** | Рендер у PNG і перегляд очима після кожної зміни | Вихід графіка за поля, накладання легенди, неграмотний заголовок, англійські слова в українському звіті, розрив підписів; **регресія** застереження про приховані країни |
| **Кольори графіків** | Валідатор палітри (дальтонізм, контраст) | Перший варіант бірюзового не пройшов |
| **Чистота експерименту** | Ізоляція прогонів | **Перший baseline забруднений:** агент прочитав очікувані відповіді з репо. Прогони перенесено в тимчасові теки з пакетом навички |
| **Пакет навички** | Тест «запакована навичка запускається сама» | Встановлена навичка не запустилася б: `pyproject` посилався на файл поза пакетом |
| **Поведінка агента** | Читання кожного транскрипту на Кроці 7, далі автоматичні перевірки + LLM-суддя | 12 проблем на Кроці 7, ще 5 у бенчмарку (див. [evals/results](../evals/results/)) |
| **Самі тести** | Порівняння очікувань з тим, що правильно по суті | **4 хибні очікування в моїх тестах** виправлено й чесно позначено (наприклад, «спитати мови до завантаження навички» — правильна поведінка) |

## Де AI помилявся найчастіше (і чого це навчило)

1. **Правдоподібні, але неперевірені припущення про дані.** Звідси правило: кожен тестовий сценарій спершу перевіряється на живих даних.
2. **Перевірки, які «проходять», але нічого не перевіряють** (fact-check v1). Звідси правило: кожну перевірку спершу треба побачити такою, що **падає**.
3. **Дрібна неакуратність у скриптах:** zsh не розбиває змінні на слова; `sed`-заміни не застосовувалися після переформатування. Звідси: після кожної масової правки — повторний прогін лінтера й тестів.
4. **Надмірна довіра до інструкцій для маленької моделі.** Правила в `SKILL.md` Haiku виконувала через раз. Звідси архітектурне рішення: критичні підказки йдуть у вивід CLI, а критичні дії — у код ([DESIGN, 4.4](DESIGN.md#44-підказки-у-виводі-а-не-лише-в-skillmd)).

## Що автор може відтворити сам

```bash
uv run pytest                                   # 143 тести
uv run pytest -m live                           # звірка з живим API
uv run --with scipy python dev/verify_stats.py  # статистика проти SciPy
cd evals && uv run python run.py report         # перерахувати бенчмарк із збережених прогонів
```
