# Крок 9: автоматичний бенчмарк

**Дата:** 2026-09-24.
**Навичка:** v0.1.0.
**Модель:** Claude Haiku 4.5 (Claude Code 2.1.281, headless, підписка).
**Суддя:** Claude Sonnet.
**Free-модель:** dots-3-note-preview через [власний агент](../../../dev/harness/agent.py).

Повна таблиця лежить у [`benchmark.md`](benchmark.md), сирі агрегати в [`benchmark.json`](benchmark.json), результати першої версії в [`benchmark-v1.md`](benchmark-v1.md). Кожен прогін має теку в `runs/` або `triggers/`, де лежать `transcript.md`, `run.json`, `checks.json` і `judge.json`.

Відтворити:

```bash
cd evals
uv run python run.py cases --envs clean,baseline,realistic   # 14 сценаріїв; вже виконані пропускаються
uv run python run.py triggers --envs clean --runs 3
uv run python run.py triggers --envs realistic --runs 1
uv run python run.py openrouter --model dots-studio/dots-3-note-preview:free --cases astronomy-uk-trust,fasting-pl-cs
uv run python run.py judge && uv run python run.py report
```

### Чому не 100% за числами (і чому це нормально показати)

Усі 3 провали — це **справжні помилки моделі**, і саме fact-check їх виявив:
- `followup-add-lang`, прогін 2: «довіра висока (85)», а в даних 80. Модель вигадала число;
- `resume-session`, прогін 2: «польська на 31 п.п. більш стійка». Модель сама порахувала різницю, хоча `SKILL.md` це забороняє;
- `custom-weights`, прогін 2: «на 2,7% швидше втрачає». Та сама помилка, похідне число.

У чаті ці відповіді fact-check не блокує (у PDF блокує). У `SKILL.md` є команда `wir check`, але Haiku не завжди її викликає. Наступний крок (див. roadmap): робити перевірку обов'язковою, наприклад через hook агента або поле у виводі `report`/`study`.

## Ітерація v1 → v2

Після першого прогону бенчмарку зміни вносилися **лише за знайденими проблемами**. Їх видно в транскриптах і поясненнях судді:

| Сценарій | Перевірки v1 → v2 | Суддя v1 → v2 | Що змінено |
|---|---|---|---|
| english-learning-report | 87% → 100% | 2.9 → **4.0** | Після створення PDF повна відповідь лишається в чаті; рекомендації йдуть за рейтингом і формулюються як «перевірити»; прихована країна означає невідомий розмір, а не «найбільшу аудиторію» |
| news-spike | 50% → 100% | 1.4 → **3.7** | «Conclave» більше не неоднозначний через однойменний фільм: твори, названі на честь поняття, не створюють неоднозначності |
| english-query | 93% → 100% | — | Мова відповіді й звіту = мова користувача (раніше англійський запит отримав українську відповідь) |
| resume-session | 67% → 75% | — | Опис навички тепер згадує продовження збереженого дослідження; 1 з 3 прогонів усе ще не вмикає навичку |
| english-learning-no-langs | 67% → 100% | — | Виправлено **хибне очікування тесту**: спитати мови до завантаження навички — правильна поведінка |

Додатково `study update` тепер повертає `changes_since_previous_state`, наприклад «sk: verdict unclear → declining; trust Medium (45) → High (80)». Це допомагає моделі в уточненнях, а fact-check знає ці числа.
