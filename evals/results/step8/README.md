# Крок 8: навичка на безкоштовних моделях OpenRouter

**Дата:** 2026-09-24.
**Агент:** власний, [`dev/harness/agent.py`](../../../dev/harness/agent.py), ~300 рядків.
**Раннер:** [`evals/openrouter.py`](../../openrouter.py). Ізоляція та сама, що для Claude Code: тимчасова тека й лише пакет навички.

## Навіщо власний агент

Завдання вимагає перевірити навичку на дешевій моделі й **не прив'язуватися до Claude**. Власний агент:
- **показує, що навичка працює за специфікацією Agent Skills, а не завдяки особливостям Claude Code.** Модель бачить лише `name`, `description` і шлях до `SKILL.md` (блок `<available_skills>` у форматі `skills-ref to-prompt`). Далі вона сама читає `SKILL.md` і запускає скрипти, тобто поступове розкриття зі специфікації;
- **дає повний контроль і повні логи:** кожен запит, виклик інструмента, токени й повтори;
- **пише результати в тому самому форматі, що й прогони Claude Code**, тож `evals/checks.py` оцінює обидва однаково.

**Інструменти:** `bash`, `read_file`, `write_file` у стилі OpenAI tool calling.

**Захист:**
- змінні середовища з `KEY/TOKEN/SECRET` прибрано з оточення команд: модель не бачить ключ OpenRouter, і тест це перевіряє;
- явно руйнівні команди (`sudo`, `rm -rf /`, `mkfs`…) відхиляються;
- вивід обрізається до 12 тис. символів;
- прогони йдуть у тимчасовій теці.

## Реальність безкоштовних моделей

З 18 безкоштовних моделей з підтримкою tools у момент тестування:

| Модель | Доступність |
|---|---|
| `dots-studio/dots-3-note-preview:free` | ✅ стабільно |
| `nvidia/nemotron-3-super-120b-a12b:free` | ⚠️ спершу 503, потім працювала (2 повтори на прогін) |
| `google/gemma-4-31b-it:free` | ❌ 429: спільний пул провайдера перевантажений, 7 повторів поспіль |
| `qwen/qwen3.8-27b:free` | ❌ 429 весь час |
| `thinkingmachines/inkling:free` | ❌ 403 «only available on agentic harnesses» |

Висновки:
- **повтори з паузою** (5/15/30/60/90 с) обов'язкові;
- **перелік моделей має бути гнучким**, раннер приймає будь-яку модель у `--model`;
- **ліміт free tier (~50 запитів на день)** не дозволяє робити великий бенчмарк на безкоштовних моделях. Для Кроку 9 беремо невеликий набір сценаріїв.

## Результати

| Модель | astronomy-uk-trust | fasting-pl-cs | english-learning-report |
|---|---|---|---|
| dots-3-note-preview | **7/7** (4 виклики) | **8/8** (2 виклики) | 5/10 → **10/10** після виправлення агента |
| nemotron-3-super-120b | 6/7 | **8/8** (сама перевірила відповідь через `wir check`) | — (економія квоти) |
| *для порівняння:* Haiku 4.5 (Крок 7) | 7/7 | 8/8 | 10/10 |

**Що спрацювало:**
- **Обидві моделі самі знайшли й прочитали `SKILL.md`, запустили `wir`**, не робили жодних спроб завантажити дані іншим шляхом і не вигадали жодного числа (`numbers_match_study` пройдено скрізь).
- **dots-3 у прикладі 3 пройшла весь «правильний» шлях.** Вона перевірила `resolve` для «learning English», побачила хибне поняття (програма VOA), обрала `Q1860` і зібрала PDF. Fact-check двічі відхилив її текст, і вона двічі його виправила.
- **Підказки у виводі CLI працюють і для не-Claude моделей.** Приховані читачі з В'єтнаму описані як «точний розподіл невідомий», без фантазій про «більшу аудиторію».
- **Nemotron сама викликала `wir check`** для перевірки своєї відповіді. Це підтверджує, що інструкції в `SKILL.md` читаються.

**Що знайдено й виправлено:**
- **Порожня відповідь посеред задачі.** dots-3 після запису файлу повернула пусту відповідь без виклику інструмента, і агент вважав задачу завершеною. Тепер агент до 2 разів нагадує «продовж; якщо закінчив, дай відповідь». Це відомий патерн агентних циклів. Після виправлення прогін дав 10/10.
- **Хибне спрацювання перевірки `no_invented_titles`.** Кандидати на проксі від CLI вважалися вигаданими назвами. Виправлено.

**Що лишається обмеженням:** мовна якість відповіді залежить від моделі.
- **Nemotron:** «довериво», «zmieniła», «печери». Через спотворене «довіра» перевірка `mentions_trust` чесно провалилася.
- **dots-3:** трапляються русизми («Прямая», «суточно»).

Навичка контролює **що** сказано (числа, довіра, обмеження), але не **як**. Для українських звітів ми рекомендуємо моделі з сильною українською; Haiku тут помітно краща.

## Як відтворити

```bash
cp .env.example .env   # вписати OPENROUTER_API_KEY
uv run python evals/openrouter.py --case astronomy-uk-trust --model dots-studio/dots-3-note-preview:free --out /tmp/runs
# або вручну, з будь-якою текою та навичкою:
uv run python dev/harness/agent.py --model <model> --skills <dir-with-skills> --workspace /tmp/ws "<запит>"
```
